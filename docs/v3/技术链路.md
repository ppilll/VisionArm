# ONNX → RKNN → RK3588 NPU 技术链路

## PC 转换链
```
Pretrained Model
      ↓
     ONNX
      ↓
ONNX Checker
      ↓
Reference Inference
      ↓
Preprocessing Contract
      ↓
RKNN-Toolkit2
      ↓
FP / INT8 Build
      ↓
    .rknn
      ↓
SHA-256 + Manifest
```
ONNX 官方提供 onnx.checker.check_model() 做模型合法性检查；shape inference 可以辅助分析静态/符号维度，但官方也明确指出 shape inference 并非总能推导完整动态 shape，所以不能把“shape inference 没有补全所有尺寸”自动等同于模型损坏。

## RK3588 Runtime 链
```
.rknn
 ↓
rknn_init
 ↓
rknn_query
 ├─ RKNN_QUERY_SDK_VERSION
 ├─ RKNN_QUERY_IN_OUT_NUM
 ├─ RKNN_QUERY_INPUT_ATTR
 └─ RKNN_QUERY_OUTPUT_ATTR
 ↓
Input Tensor
 ↓
rknn_inputs_set
 ↓
rknn_run
 ↓
rknn_outputs_get
 ↓
Raw Output Tensor
 ↓
rknn_outputs_release
 ↓
rknn_destroy
```

python3 convert.py ../model/yolov8n.onnx rk3588
