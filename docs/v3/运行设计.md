
# RKNN 运行时设计
责任
输入张量
→ Rknn引擎
→ 输出张量
RknnEngine 严禁拥有摄像头/UART/音频/网络。
生命周期
LoadModel
→ rknn_init
→ QueryVersion
→ QueryModel
→ Infer
→ rknn_outputs_release
→ rknn_destroy
## 错误处理
必须检查每个RKNN返回码。
线程安全
V3 假设：单线程使用。
V7 要求：  
一个 RknnEngine 实例可以由推理线程拥有，且无需与摄像头或控制模块耦合。
## 接口
- Init(model_path)  
- Infer(input, outputs)  
- GetModelInfo()  
- Shutdown()
