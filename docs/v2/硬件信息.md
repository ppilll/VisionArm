# Sensor 到 CSI/CIF 的前端链路已完整

当前有效路径是：

IMX415
  ↓
rockchip-csi2-dphy0
  ↓
rockchip-mipi-csi2
  ↓
RKCIF

D-PHY 的 Sink pad 接收 IMX415，Source pad 输出到 CSI-2 receiver，两个 link 都是 [ENABLED]

CSI-2 receiver 的输入格式为：

SGBRG10_1X10 / 3864x2192
crop 3840x2160

其 pad1 默认连接到：

stream_cif_mipi_id0
/dev/video11

# CIF 到 ISP0 的链路也已建立

/dev/media2 属于：

driver: rkisp0-vir0
model: rkisp0

并且 ISP 的输入来自：

rkcif-mipi-lvds2

其中包含 /dev/video22 到 /dev/video30

所以当前系统中已经存在两类可选采集节点：

/dev/video11
    RKCIF 直接输出
    通常是 IMX415 RAW Bayer

rkisp0 对应的 rkisp_mainpath
    ISP 处理后输出
    通常可以选择 NV12、NV21、YUYV 等格式

选择理由：

内存大小和 plane 布局明确；
帧率来自当前 IMX415 sensor 模式。

1. 应用 QBUF
2. buffer 进入驱动的 queued 队列
3. ISP DMA 开始写入 buffer
4. 一帧结束，硬件触发中断
5. 驱动中断处理程序：
       标记 buffer 完成
       填写 timestamp
       填写 sequence
       填写 bytesused
       将 buffer 放入 done 队列
       唤醒等待队列
6. poll/select 被唤醒
7. 应用 DQBUF 取出该 buffer
