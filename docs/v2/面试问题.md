## 13. 面试可讲点和阶段准入条件

V2 完成后可讲：

1. Linux V4L2 用户态采集流程；
2. `QUERYCAP` 和 `device_caps`；
3. `/dev/videoX` 如何映射到实际硬件；
4. USB UVC 多 video node 的识别；
5. Media Controller topology；
6. single-planar 与 multi-planar；
7. MJPG、YUYV、NV12 的工程取舍；
8. `REQBUFS、QUERYBUF、mmap、QBUF、DQBUF`；
9. incoming/outgoing buffer queue；
10. poll 和非阻塞采集；
11. sequence gap 和掉帧统计；
12. V4L2 timestamp 类型和来源；
13. 为什么不能把 DQBUF 时间直接等同于曝光时间；
14. 如何为后续音视频同步保留时间戳；
15. 为什么不用 OpenCV VideoCapture 替代底层证据；
16. 如何定位 USB 带宽和摄像头稳定性问题；
17. 如何设计安全退出和资源回收；
18. 如何将 Camera 模块封装为后续 RKNN pipeline 的输入。
