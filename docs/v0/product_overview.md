# VisionArm BallTrack 产品定义

## 1. 产品一句话定位

VisionArm BallTrack 是一个基于 RK3588、摄像头、麦克风、MCU/RTOS 二自由度云台、网络和本地存储的边缘视觉足球追踪与音视频回传/录制系统。

完整产品描述：

系统在 RK3588 上采集摄像头画面，使用预训练足球分割模型识别足球位置，计算足球中心点相对画面中心的偏差，通过 UART 将控制量发送给 MCU/RTOS 云台控制器，由 MCU 驱动云台调整摄像头方向，使足球尽量保持在画面中心。

系统同时采集麦克风音频，对视频帧和音频数据进行时间戳管理与音视频同步。系统将带有足球识别标注、云台状态、延迟信息的视频与音频进行封装，并根据配置：

回传到 PC 上位机；
保存为本地音视频文件；
可选同时回传和保存；
本地保存目标介质优先考虑 SD 卡或其他可移动存储。

这个项目不是“模型能识别足球”的 AI demo，也不是“摄像头能打开”的简单演示，而是一个包含采集、推理、控制、通信、音视频处理、网络输出、本地存储和测试报告的完整产品。

## 2. 产品不是 AI Demo

本项目不是“模型能识别足球”的演示程序。

本项目的核心是完整的嵌入式 Linux 智能硬件闭环：

```text
Camera/V4L2 采集
→ 图像预处理
→ RKNN/NPU 推理
→ 足球 mask 后处理
→ 中心点/半径/置信度计算
→ 偏差 dx/dy 计算
→ Linux → MCU/RTOS 通信
→ 云台舵机控制
→ 摄像头方向调整
→ 视频或状态回传上位机
→ 性能测试与报告
