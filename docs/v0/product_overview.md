# VisionArm BallTrack 产品定义

## 1. 产品一句话定位

VisionArm BallTrack 是一个基于 RK3588 + 摄像头 + MCU/RTOS 云台的边缘视觉足球追踪与视频/状态回传系统。

系统在 RK3588 上采集摄像头画面，使用预训练足球分割模型识别足球位置，计算足球中心点相对画面中心的偏差，通过 UART 将控制量发送给 MCU/RTOS 云台控制器，由 MCU 驱动云台调整摄像头方向，使足球尽量保持在画面中心，同时将带标注、状态和延迟信息的视频或状态数据回传到上位机。

## 2. 产品不是 AI Demo

本项目不是“模型能识别足球”的演示程序。

本项目的核心是完整的嵌入式 Linux 智能硬件闭环：

```text
Camera/V4L2 采集
→ 图像预处理
→ RKNN/NPU 推理
→ 足球 mask 后处理
→ 中心点/半径/置信度计算
→ 偏差 dx/dy 计算
→ Linux → MCU/RTOS 通信
→ 云台舵机控制
→ 摄像头方向调整
→ 视频或状态回传上位机
→ 性能测试与报告
