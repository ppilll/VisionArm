# VisionArm BallTrack V7 Visual Servo Architecture

## 1. Purpose

本文定义 VisionArm BallTrack V7 的图像空间视觉伺服闭环架构。

V7 目标：

摄像头
→ 检测
→ 图像误差
→ RS-485
→ STM32
→ 视觉伺服控制器
→ S20F 命令
→ 摄像头运动
→ 新图像误差

目标闭环变量：

ex → 0
ey → 0

---

## 2. Frozen Baselines

### V4 — RK3588 Perception

冻结：

- V4L2 MMAP + VIDIOC_EXPBUF + DMA-BUF
- CaptureBufferBroker / FrameLease
- RGA preprocess
- RKNN / YOLOv8
- latest-frame inference queue
- MPP video path
- TargetState semantics

禁止为了 V7 重构上述数据面。

### V5 — Communication

冻结：

- RS-485 / USART2
- framing
- escaping
- CRC
- parser
- transaction cache
- CONTROL_UPDATE semantics
- ControlMailbox latest-value semantics
- link watchdog
- control freshness watchdog

### V6 — Actuator / Safety

冻结：

Pan:
- 1000–2000 us
- center = 1500 us
- PWM increase → Camera LEFT

Tilt:
- 1200–1600 us
- center = 1500 us
- PWM increase → Camera DOWN

SafetyGate 保持原语义。

---

## 3. System Plant

本项目外部 plant 包括：

STM32 执行器命令  
→ S20F 内部伺服位置闭环  
→ 机械云台/倾斜  
→ 相机光轴变化  
→ 图像特征变化

S20F 自身具有内部位置控制。

本系统没有：

- external encoder
- measured servo angle
- measured joint position

因此 MCU 中的 PWM command 不是 measured position。

---

## 4. Image Feature

目标特征：

football bounding-box center

定义：

cx_target
cy_target

图像中心：

cx_image
cy_image

---

## 5. Error Definition

Normalized image error:

ex = (cx_target - cx_image) / normalization_x
ey = (cy_target - cy_image) / normalization_y

协议表示：

error_x_q15
error_y_q15

范围：

[-32767, +32767]

最终精确定义以 RK3588 当前代码为准。

## 6. 外部视觉循环

```text
       +-----------------------------+
       |                             |
       v                             |
Camera → YOLO → Image Error → 控制器
                             |
                             v
                          伺服指令
                             |
                             v
                         S20F Gimbal
                             |
                             +----→ 相机方向

```

## 7. 控制器位置

RK3588：

- 检测
- 目标状态
- 归一化图像误差
- 新鲜度滤波
- CONTROL_UPDATE 生成

STM32：

- SafetyGate
- 基于生成的视觉控制器
- 执行器斜率
- 软件限幅
- TIM3 PWM 输出
