# 1.产品介绍
VisionArm BallTrack 是一个基于 RK3588 + 摄像头 + 麦克风 + MCU/RTOS 二自由度云台 + 网络 + 本地存储的边缘视觉足球追踪与音视频回传/录制系统。

完整产品描述：

系统在 RK3588 上采集摄像头画面，使用预训练足球分割模型识别足球位置，计算足球中心点相对画面中心的偏差，通过 UART 将控制量发送给 MCU/RTOS 云台控制器，由 MCU 驱动云台调整摄像头方向，使足球尽量保持在画面中心。

同时，RK3588 通过板载 ES8388 Audio Codec 和板载驻极体麦克风采集环境音频。

系统后续需要对视频和音频建立统一时间基线并完成音视频同步，将带足球识别标注、云台状态、系统状态和延迟信息的视频与麦克风音频进行编码/封装，然后根据产品配置：

回传到 PC 上位机；
保存成带声音的视频文件到本地 SD 卡；
可选同时执行网络回传和本地录制；
保存相应测试日志和性能数据。
